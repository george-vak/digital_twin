ОТЧЁТ ОБ ЭКСПЕРИМЕНТЕ 2

Задача: прогноз 53 переменных (41 CV + 12 MV) на 1 минуту вперёд.
Штатный режим симулятора; шаг 60 с. Данные 20 000/5000/5000:
train — seeds 1–4, validation — seed 6, test — seed 7.

Модели и подготовка данных: В обоих экспериментах использована одинаковая архитектура: 
GRU со скрытым состоянием размерности 64 и линейным выходным слоем на 53 переменные. 
В exp_1 загружены сохранённые веса модели, ранее обученной на уровнях 
исходного ряда. В exp_2 выполнено одно обучение на первых разностях 
с seed = 42, без повторных запусков. Первые разности вычисляются при 
подготовке данных и стандартизируются: для каждой переменной вычитается 
среднее обучающих разностей, после чего результат делится на их 
стандартное отклонение, рассчитанное с ddof = 0. Параметры стандартизации
определяются только по обучающей выборке. Входное окно exp_1 содержит 
60 последовательных уровней, а exp_2 — 60 последовательных разностей, 
для вычисления которых требуется 61 исходное наблюдение.

Обучение модели exp_2: функция потерь MSE на стандартизованных разностях, 
Adam, lr=0.001, batch=256. Сначала обучал до 30 эпох, early stopping=5; 
ранняя остановка не сработала - увеличил количество эпох до 100 с таким же
парметром ранней остановки. Выбирается минимум validation MSE. 
Ранняя остановка сработала на 87 эпохе.
Лучшая эпоха exp_2: 82; validation MSE разностей: 0,518141.

Сравнение: exp_1 и exp_2 проводилось на данных 20_5_5 при горизонте
прогнозирования h = 1. Дополнительно оценивалась наивная модель,
прогнозирующая следующее значение равным последнему известному наблюдению.
Для обоих экспериментов использовалось одинаковое разбиение на обучающую,
валидационную и тестовую выборки. В exp_1 входными данными служили уровни 
исходного ряда, в exp_2 — первые разности, вычисленные внутри каждого
отдельного прогона данных. Разности между концом одного прогона и началом 
другого не рассчитывались.
Для каждой переменной отдельно определялись параметры стандартизации:
в exp_1 — среднее и стандартное отклонение обучающих уровней, в exp_2
обучающих разностей. Стандартное отклонение рассчитывалось с ddof = 0.
Полученные параметры применялись к соответствующим валидационным и
тестовым данным без повторного расчёта.

Формирование общих тестовых данных: Вход exp_1 содержал 60 последовательных 
уровней, а вход exp_2 — 60 последовательных разностей, для расчёта которых 
требовалось 61 исходное наблюдение. Поэтому обе модели оценивались на общих
целевых точках с индексами 61–4999 при индексации с нуля.
Всего использовалось 4939 тестовых точек.
Для каждой целевой точки модели получали окно предшествующих фактических
наблюдений и строили прогноз на один шаг вперёд. При переходе к следующей
точке окно сдвигалось и включало новое фактическое наблюдение. Таким образом,
оценивалась последовательность одношаговых прогнозов, а не один
рекурсивный прогноз на весь тестовый участок.

Вычисление тестовых ошибок: Восстановленные прогнозы и фактические уровни 
приводились к общей стандартизованной шкале с использованием параметров обучающих
уровней. Для каждой модели и переменной рассчитывались абсолютные масштабированные ошибки.
MASE_j = mean_test(|z_hat_j-z_j|) / mean_train(|z_t,j-z_(t-1),j|).
Знаменатель общий для exp_1, exp_2 и наивной модели.

По MASE exp_2 лучше exp_1: 41 переменная; хуже: 11; равны: 0.
MASE определена для 52 из 53 переменных.
Средняя MASE по определённым переменным, exp1: 1.275127.
Средняя MASE по определённым переменным, exp2: 0.789055.
Средняя MASE по определённым переменным, наивная модель: 0.998264.
Для переменной MV[11] MASE не определена.

Вывод: На базовом датасете (20_5_5) при горизонте прогнозирования h = 1 модель exp_2, обученная на
первых разностях, показала более высокую точность по MASE, чем exp_1, обученная на уровнях.
Из 52 переменных, для которых метрика определена, exp_2 оказалась точнее по 41 переменной (78,8%)
и менее точной по 11 переменным (21,2%).

Средняя MASE по этим 52 переменным составила 1,275127 для exp_1, 0,789055 для exp_2 и 0,998264 для
наивной модели. Таким образом, средняя MASE exp_2 оказалась примерно на 38,1% ниже, чем у exp_1, и
на 21,0% ниже, чем у наивной. Это свидетельствует о преимуществе exp_2 по средней MASE на рассматриваемом
тестовом датасете, однако не означает её превосходства над каждой из моделей по всем переменным.
