# Эксперимент №2: первые разности, стандартизация и MASE

Сравниваются две модели одной архитектуры: вход 53 переменные (41 CV + 12 MV),
один слой GRU на 64 компоненты, линейный выход на 53 переменные. Горизонт h=1,
шаг — одна минута. Окно — 60 точек. Код архитектуры и обучения общий: `model.py`.

## Данные и обучение

Используется существующий набор `exp_1/data/base_20_5`: 20 000 train (seeds 1–4),
5000 validation (seed 6), 5000 test (seed 7). Это набор 20_5_5 из постановки.
Дополнительный test seed 9 в это сравнение не включается.

- exp_1: сохранённая модель `exp_1/runs/original/models/gru.pt`, без переобучения.
- exp_2: одно обучение с seed 42 на обработанных данных. Повторов на пяти seed нет.
- Архитектура, Adam, lr=0.001, batch=256, MSE, до 30 эпох, patience=5 и выбор
  лучшей эпохи по validation MSE сохраняются.

`preprocess.py` отменяет исходную стандартизацию, считает первые разности
внутри каждого run_id и split и стандартизует их:

```text
delta_x(t) = x(t) - x(t-1)
u(t) = (delta_x(t) - mean_train_delta) / std_train_delta
```

Mean и std (ddof=0) вычисляются только по train. Для постоянного столбца
масштаб заменяется на 1. Получается 19 996 обучающих разностей и по 4999
валидационных и тестовых разностей. Производные данные и их нормализация
сохраняются внутри нового запуска, в `data/differenced/`.

При оценке прогноз разности переводится обратно в исходную шкалу и
прибавляется к последнему известному уровню:

```text
x_hat(t+1) = x(t) + u_hat(t+1) * std_train_delta + mean_train_delta
```

В каждое окно поступает фактическая история. Предыдущие прогнозы на вход
следующим окнам не подаются.

## Общая оценка

`evaluate_mase.py` заново получает прогнозы обеих сохранённых моделей и
сопоставляет их по `(run_id, step)`. При окне 60 разностей нужны 61 исходное
наблюдение: общие цели — шаги 61…4999, всего 4939. Первая из 4940 прежних
целей exp_1 исключается. Объём исходной истории отличается на одну точку:
exp_1 использует 60 уровней, exp_2 — 60 разностей из 61 уровня.

Для оценки уровни стандартизуются по train исходного ряда, одинаково для
обеих моделей. Это отдельная шкала, отличная от стандартизации разностей
при обучении. Для каждой переменной j:

```text
d_j = mean_train(|z_t,j - z_(t-1),j|)
a_t,j = |z_hat_t,j - z_t,j| / d_j
MASE_j = mean_test(a_t,j)
std_j  = std_test(a_t,j, ddof=0)
```

Train-знаменатель общий для exp_1, exp_2 и эталона persistence. В него входят
19 996 соседних пар внутри обучающих прогонов; переходы между seeds исключены.
MASE ± std отражает среднее и разброс масштабированных абсолютных ошибок
по тестовым точкам каждой переменной. Это не доверительный интервал и
не разброс повторных обучений. Результаты seed 7 и seed 9 не смешиваются.

Для постоянной MV[11] d_j=0: MASE и её std записываются как NA, переменная
исключается из агрегатов MASE, но её MAE в стандартизованной шкале сохраняется.
Ноль не заменяется epsilon. Для остальных переменных также сохраняются MAE_z,
описания, единицы и знаменатели. Макросредняя MASE даёт каждой определённой
переменной одинаковый вес; она подписывается отдельно от временного std.

Определение MASE: [Hyndman & Athanasopoulos](https://otexts.com/fpp3/toolbox.html#scaled-errors).
Линейное масштабирование уровней не меняет MASE, если числитель и знаменатель
масштабируются одинаково. Здесь знаменатель рассчитан по уровням, не по
вторым разностям и не по ошибкам эталона на test.

## Запуск из корня репозитория

```bash
source .venv/bin/activate
# Проверить последовательность команд
python exp_2/run.py --run first --train --dry-run
# Подготовить данные, обучить одну GRU и сравнить с сохранённой exp_1
python exp_2/run.py --run first --train
# Повторная оценка уже обученной exp_2 без нового обучения
python exp_2/run.py --run recheck --source-run first
```

`--run` должен быть новым. Новое обучение требует `--train`; без него используются существующие веса
из `--source-run`. Выполненный первый запуск уже сохранён под именем `first`. Повторная оценка копирует выбранный checkpoint и сравнивает его
с той же сохранённой exp_1. Все настройки — в `config.json`.

В `runs/<имя>/` сохраняются:

- `models/`: веса и история единственного обучения;
- `data/differenced/`: производные данные (при `--train`);
- `results/mase_comparison.csv`: `variable`, `MASE1`, `MASE2`, `imp_percent`;
  положительный `imp_percent` — снижение MASE exp_2 относительно exp_1;
- `results/.metadata/mase_details.json`: подробные метрики, включая std,
  persistence и MAE_z; основная таблица остаётся компактной;
- `results/predictions_*_levels.csv.gz`, `actual_levels.csv.gz`: прогнозы и факты
  на общих тестовых точках в исходных единицах;
- `results/summary.json`: сводка, общий train-знаменатель, нормализация и хеши;
- `plots/01_mase_comparison.png`: сопоставление MASE и изменения по переменным;
- `plots/02_mase2_by_variable.png`: столбчатая диаграмма MASE2, по X — CV/MV;
- `reports/experiment_report.txt`: краткий научный отчёт;
- `config.json`, `manifest.json`, `logs/run.log`: настройки и протокол выполнения.

Исходный эксперимент №1 и его результаты h=1, 5, 10 сохраняются. Все новые
сравнения используют h=1; исторический отчёт MAE не подменяется расчётом MASE.


## Результат выполненного запуска first

Одна GRU обучена с seed 42; лучшая эпоха — 30 из 30.
На 4939 общих тестовых точках exp_2 лучше exp_1 по MASE для 37 переменных,
хуже для 15. MASE определена для 52 переменных; MV[11] исключена из агрегата.

| Модель | Средняя MASE по 52 переменным |
|---|---:|
| exp_1, уровни | 1.275127 |
| exp_2, разности | 0.856645 |
| Persistence | 0.998264 |

Снижение этой макросредней относительно exp_1 — 32.82%, относительно
persistence — 14.19%. Это агрегаты по переменным; временные mean ± std
для каждой переменной находятся в `results/.metadata/mase_details.json`.
exp_2 превосходит persistence по 29 из 52 определённых переменных.
Вариативность повторных обучений и статистическая значимость не оценивались.
