# Базовое обучение управления

Запуск:

```bash
.venv/bin/python exp_3/run.py --run next
```

Нужно новое имя запуска. На macOS должен работать Docker с образом
`temain-simulator:local`. На Linux x86-64 доступен прямой запуск симулятора.

## Файлы

- `config.json` — параметры обучения.
- `networks.py` — преобразование данных, актёр, модель CV, стоимость.
- `simulator.py` — прогрев, применение MV, получение CV и завершение эпизода.
- `run.py` — сбор переходов, буфер и обновление двух сетей.
- `plot.py` — графики сохранённых результатов.

## Алгоритм

GRU из exp_2 обучена на историческом наборе 20_5_5. В этом эксперименте
используются её веса и нормализация. Сами исторические CSV повторно не читаются.
Новые обучающие переходы получает симулятор.

Актёр получает 60 нормализованных разностей CV/MV и выдаёт изменение 12 MV.
После восстановления физических значений команда с небольшим шумом подаётся
в симулятор на одну минуту. Следующее наблюдение добавляется в историю,
самое старое удаляется.

Модель CV получает ту же историю и отдельным входом выбранное изменение MV.
Она предсказывает 41 разность CV и обучается по фактическому результату
симулятора. Критик в этой схеме — модель CV вместе с формулой стоимости.

Актёр обучается минимизировать стоимость прогнозных CV следующего шага.
Во время его обновления веса модели CV фиксированы, но градиент проходит
через неё к актёру. Стоимость повторяет TemainAnalyser; отдельного штрафа
за аварию или выход CV за ограничения нет. Остановка завершает эпизод,
но сама по себе не штрафует актёра. Накопленная будущая стоимость не обучается.

Прогрев — 1000 минутных шагов. Последние 61 наблюдение формируют первое окно.
Сначала собираются 200 переходов, затем выполняются 100 обновлений модели CV.
Далее каждый шаг среды сопровождается обновлением модели и актёра по случайным
64 переходам из буфера. Веса и буфер сохраняются между эпизодами.

Эпизод заканчивается через 200 шагов или при неизменности всех CV три шага
подряд. Обучение заканчивается после 10 эпизодов. Все параметры в config.json.
Проверки конечности чисел и состояния симулятора оставлены, чтобы не обучаться
на NaN или замершем после прогрева процессе.

## Результаты

В `runs/<имя>/` сохраняются:

- `config.json` — использованные параметры;
- `controller.pt` — веса актёра и модели CV, нормализация и параметры;
- `steps.csv` — CV/MV, стоимость, losses и завершение на каждом шаге;
- `summary.json` — стоимость и длительность эпизодов;
- `plots/` — графики стоимости, обучения сетей и всех CV/MV последнего эпизода.

Графики создаются автоматически. Перестроить их отдельно:

```bash
.venv/bin/python exp_3/plot.py --run current
.venv/bin/python exp_3/plot.py --run current --episode 0
```

В `runs/current/` лежат результаты текущей реализации с параметрами из
`config.json`. Предыдущие запуски удалены. Для нового обучения используйте
новое имя запуска. Возобновление обучения с сохранением буфера и состояния
симулятора не реализовано.
