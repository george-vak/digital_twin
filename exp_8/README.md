# exp_8. Актор и замороженный Q-критик для удержания цены 160

Цель — хотя бы 200 последовательных минутных шагов с ценой в диапазоне 155–165 при малом разбросе цены внутри серии. На вход в диапазон даётся время до начала серии. Эпизод длится до 300 шагов после 1000 шагов прогрева. Три последовательных неизменных наблюдения CV означают остановку симулятора. Выход за CV-границу записывается и штрафуется, после чего эпизод продолжается.

Итоговые метрики и выбор конфигурации приведены в [основном отчёте](runs/rebuilt/report.md).

## Сбор данных

Из исходного симулятора берётся история из 61 состояния, содержащая 60 разностей всех 53 переменных. На каждой выбранной минуте симулятор клонируется семь раз из одного состояния. На первом шаге каждая копия получает одну команду. Первая ветка получает номинальную команду, рассчитанную встроенным регулятором на отдельной копии. Шесть других получают положительные и отрицательные возмущения до 1,5 процентного пункта на активных MV. Далее встроенный регулятор ведёт каждую ветку до горизонта 20 шагов. Главный экземпляр между точками сбора остаётся под встроенным управлением, с отдельными возмущениями для расширения покрытия состояний.

Сиды сбора, валидации модели, обучающих эпизодов актора, валидации актора и итоговой оценки разделены и записаны в [конфигурации](config.json). Все ветки одного состояния относятся к одному разбиению. Набор хранится по seed с протоколом и SHA256 исходников симулятора и сбора.

## GRU

Сравниваются исходная GRU из exp_2, дообученная GRU по истории и дообученная GRU по истории с командой MV. Дообученные варианты прогнозируют уровни 41 CV и 12 MV через 1, 5 и 10 минут при одном внешнем действии и дальнейшем встроенном управлении. На этих горизонтах сравниваются MAE уровней и RMSE цены, вычисленной из прогнозных CV. Для исходной GRU дальние горизонты строятся рекурсивно. Модель выбирается по сумме трёх RMSE цены на отложенных seed.

На шаге управления прогноз GRU вычисляется для номинальной команды. Её знает актор до выбора своей поправки. Обе управляющие головы получают прогноз стандартизованных изменений всех 53 каналов на один шаг, текущие нормированные уровни 52 активных переменных, ошибку цены и оставшуюся долю эпизода. Q дополнительно получает предлагаемое отклонение команды от номинальной.

## Q-критик

Q оценивает дисконтированный возврат за 20 минут после конкретной команды при дальнейшем встроенном управлении. Цель для ветки равна

\[
G=-\frac{\sum_{k=0}^{19}\gamma^k \ell_{k+1}}{\sum_{k=0}^{19}\gamma^k}.
\]

В \(\ell\) входят квадрат ошибки цены с масштабом 5 и штрафы по CV и MV. После остановки в остаток ветки подставляется штраф остановки. Для CV границы вычисляются как P1/P99 по прогреву, для MV используется диапазон [0,100]. Штраф внутри интервала строится из логарифмов нормированных запасов до обеих границ. При запасе меньше \(\epsilon=0{,}1\) логарифм гладко продолжается квадратичной функцией со стыковкой до второй производной. Для точечной границы применяется квадратичное отклонение. Средний штраф \(B\) каждой группы каналов входит в стоимость в виде \(\log(1+B/10)\). Это снижает влияние очень узких интервалов CV при больших отклонениях.

Критик обучается на абсолютных возвратах и разностях с номинальной командой из того же состояния. На валидации сохраняются доля правильно упорядоченных пар, RMSE разницы возвратов и средняя потеря при выборе команды с максимальным прогнозным Q вместо лучшей проверенной команды. Для сравнения критики на исходных и новых признаках используют одни и те же ветки и цели. При обучении актора веса выбранной GRU и Q фиксируются, SHA256 сверяется после оптимизации.

## Актор в гибридном запуске rebuilt

Между эпизодами актор обучается на сохранённых состояниях, включая состояния из его собственных эпизодов. Он выдаёт 11 ограниченных поправок к номинальной команде. Остальные минуты управляет встроенный регулятор. MV[11] на внешнем шаге сохраняет значение прогрева. В функционале актора есть отрицательный Q, отдельный штраф за модуль фактического изменения MV, оконный штраф относительно средних MV и штраф за величину отклонения от номинальной команды.

Кандидаты меняют скорость обучения, период поправок и вес штрафа за отклонение от номинала. Checkpoint выбирается по числу успешных 200-шаговых серий, затем по медиане и среднему длины непрерывной серии, RMSE серии и общей MAE. На итоговых seed сравниваются выбранный актор, чистое встроенное управление и внешняя подача номинальной команды по расписанию актора. Это последнее сравнение выделяет эффект выученной поправки.


Горизонт Q в 20 минут проверяет локальную целесообразность действия. В реальном эпизоде актор вмешивается повторно, поэтому 200-шаговое удержание проверяется непосредственно в симуляторе.

## Воспроизведение

Docker должен иметь локальный образ `temain-simulator:local`.

```bash
.venv/bin/python -B -m exp_8.run --phase prepare
.venv/bin/python -B -m exp_8.run --run rebuilt
MPLCONFIGDIR=/tmp/exp8-matplotlib .venv/bin/python -B -m exp_8.report --run rebuilt
MPLCONFIGDIR=/tmp/exp8-matplotlib .venv/bin/python -B -m exp_8.plot --run rebuilt
.venv/bin/python -B -m unittest discover -s tests
```

Для нового обучения используется новое имя `--run`. В каталоге запуска сохраняются веса моделей, метрики по seed, логи подбора, границы CV и последнее состояние прогрева для каждого эпизода. `plot.py --phase evaluation` строит сводный график оценки и графики всех 41 CV по каждому её эпизоду.

## Самостоятельное управление актором

В [actor_anchored](runs/actor_anchored/report.md) нейросеть после прогрева подаёт все 11 управляемых команд MV на каждой минуте. Фиксированный MV[11] берётся из прогрева. Команды ограничены относительно значений MV в конце прогрева. Горизонт, итоговые seed и правила остановки совпадают с `rebuilt`.

Актор использует признаки замороженной GRU и обучается имитации штатного регулятора. Начальный набор включает 36 штатных траекторий и команды регулятора из веток симулятора. Затем один раунд DAgger добавляет состояния, посещённые самим актором. Штатная команда запрашивается на копии симулятора только для получения учебной метки. Целевая функция учитывает ошибку имитации и штраф за величину изменения MV. Для этого сценария обучаются только веса актора.

Выбранный checkpoint хранится в [controller.pt](runs/actor_anchored/controller.pt). Сравнение стоимости за одинаковое время и длительности эпизодов приведено в [отчёте](runs/actor_anchored/report.md). Для одинаковых seed 2670–2679 доступны сводки [rebuilt](runs/rebuilt/evaluation/plots/01_episodes.png) и [actor_anchored](runs/actor_anchored/evaluation/plots/01_episodes.png). Графики всех CV лежат рядом со сводками.

```bash
.venv/bin/python -B -m exp_8.expert
.venv/bin/python -B -m exp_8.actor_only --run repeat_anchored
.venv/bin/python -B -m exp_8.actor_report --run repeat_anchored
MPLCONFIGDIR=/tmp/exp8-matplotlib .venv/bin/python -B -m exp_8.plot --run repeat_anchored
.venv/bin/python -B -m exp_8.actor_only --run actor_anchored --phase evaluation
```
