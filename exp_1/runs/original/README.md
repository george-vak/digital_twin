# Исторический запуск эксперимента №1

Содержит существовавшие до реорганизации данные результатов, веса и графики.
Обучение не повторялось. Данные перенесены в `exp_1/data/`.

`migration_manifest.json` перечисляет прежние и новые пути и SHA256 всех
перенесённых файлов. В CSV исправлены только строки путей, а в JSON отчётов —
пути и SHA256 соответствующего CSV. Числовые таблицы, веса, истории обучения,
датасеты и содержимое пользовательской папки отчёта сохранены.

`reports/` — прежняя папка «отчет1», включая пользовательские правки текста
и выбранные рисунки. Старые относительные ссылки в этом историческом тексте
относятся к подпапкам данного запуска; данные находятся в `exp_1/data/`.

Для новых вычислений используйте `python exp_1/run.py --run <новое_имя>`.
Так текущие результаты останутся отдельным исходным запуском.
